Política de Privacidade – CashTag

Última atualização: 19 de junho de 2025

1. Informações Coletadas

O aplicativo CashTagnão coleta, armazena nem compartilha dados pessoais com terceiros. Todas as informações inseridas, como receitas e despesas, são armazenadas localmente no dispositivo do usuário e não são transmitidas pela internet.

2. Armazenamento de Dados

Todos os dados fornecidos pelo usuário são mantidos exclusivamente no aparelho onde o aplicativo está instalado. Nenhuma informação é enviada a servidores ou armazenada em nuvem.

3. Permissões

O aplicativo pode solicitar permissões específicas, como acesso ao armazenamento local, apenas para garantir o funcionamento adequado da aplicação. Nenhuma dessas permissões é usada para coleta de dados pessoais.

4. Segurança

Como os dados são armazenados localmente, a segurança das informações depende das medidas adotadas pelo próprio usuário, como o uso de senhas e bloqueio de tela no dispositivo. O aplicativo não realiza criptografia dos dados locais, por isso recomenda-se a proteção do dispositivo.

5. Alterações nesta Política

Esta Política de Privacidade pode ser atualizada ocasionalmente. Quaisquer mudanças serão publicadas nesta página com a data de atualização correspondente.

6. Contato
